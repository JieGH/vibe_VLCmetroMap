# Release notes: Xarxa 1.9.0 (versionCode 10)

## What's new for users

- **The app follows your device's light or dark setting by default.** It used to start dark on the website and iPhone; now every platform starts in Auto and switches when your device does. Picking Light or Dark in the menu or the top-bar toggle still overrides it.

## Changes for the owner

- `App.jsx` starts with `themeMode='system'` and reads the OS preference on the first render; `systemTheme.js` comment updated.
- What's New: new item in en/es/ca; the "seen" key is now `xarxa_whats_new_seen_1.9.0`, so everyone sees it once.
- Version: `android/version.properties` (`versionCode=10`, `versionName=1.9.0`).

## Not verified on a device

- No Android phone was connected, so the APK was built and signed but not installed. iOS is run from Xcode.
