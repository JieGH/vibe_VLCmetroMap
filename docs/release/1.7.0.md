# Release notes: Xarxa 1.7.0 (versionCode 6)

A minor release on top of 1.6.1: search and map clean-up. Everything since 1.6.1 is `git log v1.6.1..HEAD`.

## What's new for users

- **Search finds bus stops** by name or stop number. Picking one opens it exactly as tapping the stop on the map does (#138).
- **Popular buses in the suggestions.** Before you type, the search panel lists nine buses that run between the main train stations and the city centre (10, 31, 8, 9, 59, 70, 11, 7, 6) instead of the metro line grid. Metro lines are still found by typing (#142).
- **A station picked from search behaves like a tapped one**, including its lines being highlighted (#137).
- **Station line highlight is reliable.** Tapping a station no longer sometimes leaves its lines un-highlighted while the trains react (#143).
- **A tidier map.** Zoomed out, one bus stop dot is drawn per street, and more appear as you zoom in; the EMT logo and real positions return at the usual zoom (#140).
- **Search panel fixed.** The search overlay no longer stretches over the whole screen and keeps a stable width (#139), and its opening animation no longer leaves the text cursor off the input (#141, see below).
- **Single UI.** The `?variant=` switch, the B/C layouts, the metro/bus mode toggle and the walking box are gone from production; the Variant A layout is the only one.
- Spanish and Valencian wording for the new What's New items and search labels.

## Version places changed

- `android-native/version.properties`: `versionCode=6`, `versionName=1.7.0`.
- What's New: two bullets ("Search Buses and Stops", "A Tidier Map") in `WhatsNewModal.jsx`, the en/es/ca dictionaries and its test.
- Docs: CONTEXT.md and ADR-0011 note that production ships Variant A only.
- Privacy policy: not changed. Search and the thinning use local data only; no new network requests (ADR-0011).

## Not verified on a device

- **#141** (text cursor offset when search opens in portrait): the suspected cause was removed, but it was not reproduced and the fix has not been seen on a phone.
- **#143 / #137** (line highlight on tap and from search): fixed from a code and fake-map analysis; not yet seen on a real map.
- **#140** (stop density): the 28 px cell is a first guess; tune `EMT_DOT_CELL_PX` in `src/utils/emtDotMode.js` if it looks too sparse or busy.
- Spanish and Valencian wording has not been reviewed by a native speaker.

## Known follow-ups

- Night bus lines: `emt_stops.json` has none; add them from EMT open data, then list day and night buses in the suggestions (#142).
- The #140 grid is aligned to longitude and latitude, not screen pixels; a north-south pan can rarely swap a dot.

## Steps for the owner to publish

1. `git push origin main` (Cloudflare deploys the web app).
2. `npm run build` (postbuild runs `npx cap sync ios`), then archive and upload from Xcode.
3. Build the Android bundle from `android-native` and upload it per `docs/android/release-checklist.md`, then tag `v1.7.0`.
