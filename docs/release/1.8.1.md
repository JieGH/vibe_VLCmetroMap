# Release notes: Xarxa 1.8.1 (versionCode 8)

A packaging release on top of 1.8.0. The web app and the iOS app are unchanged.

## What's new for users

- **The phone app (APK) is now Capacitor-based**: the same app as the website and the iPhone version, with the same look (dark theme by default), so it gets every feature when the website does.
- Download: `releases/latest/download/Xarxa-capacitor.apk` (was `Xarxa-android.apk`). The README and the in-app download sheet point at the new name.
- It installs next to the previous app (a different app id, `com.jielei.Xarxa`), so uninstall the old one when you are happy. Obtainium: add the repository as a new app with the APK filter `.*capacitor\.apk`.

## Changes for the owner

- The previous native Kotlin app is removed from `main` and kept, frozen, on the branch `native/kotlin-app` (commit `308e47c`); development continues on Capacitor.
- `npm run build` now also syncs the Capacitor project (`postbuild`: iOS and Android), and `npm run apk` builds and signs `android/build/Xarxa-capacitor.apk`. `scripts/release-apk.sh <tag>` also attaches it to a GitHub release.
- Version: `android/version.properties` is the only source (`versionCode=8`, `versionName=1.8.1`). What's New key: `xarxa_whats_new_seen_1.8.1`, with one bullet ("Capacitor-Based App") in en/es/ca.
- Docs moved from `docs/android/` to `docs/capacitor/`; ADR-0009 has an addendum. Privacy policy: not changed.

## Not verified on a device

- Installed by adb on one phone (a foldable, OnePlus/OPPO CPH2551): it launches, and the map, the split view, live bus times and the wave dots draw. The first-launch location prompt, the back button and a full session were not exercised.
- Spanish and Valencian wording has not been reviewed by a native speaker.

## Steps for the owner to publish

1. `git push origin main` (and `git push origin native/kotlin-app` once).
2. `gh release create v1.8.1 --notes-file docs/release/1.8.1.md`, then `scripts/release-apk.sh v1.8.1` to attach the APK.
