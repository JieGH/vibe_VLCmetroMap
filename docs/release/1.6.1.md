# Release notes: Xarxa 1.6.1 (versionCode 5)

A small release on top of 1.6.0. Everything since 1.6.0 is `git log v1.6.0..HEAD`.

## What's new for users

- **Outside Spain notice.** A small yellow note at the top right says that train and bus times may be wrong when the connection is outside Spain, for example on a VPN.
- **It notices a VPN switched on mid-session.** The country is re-checked every minute, when you come back to the tab and when the network returns. A notice you dismissed shows again if it comes back.
- **Network issue reminder.** When neither trains nor buses load, a kind reminder says the connection may not be reachable by the transport provider, or the provider may be down.
- **Fix:** after a new deploy, an open page no longer shows a blank error when its map file has been replaced; it reloads once by itself (#132).
- Spanish and Valencian wording for all of the above.

## Version places changed

- `android-native/version.properties`: `versionCode=5`, `versionName=1.6.1`.
- What's New: one new bullet ("Outside Spain Notice") in `WhatsNewModal.jsx`, the en/es/ca dictionaries and its test.
- Privacy policy: not changed. Only the two-letter country code is read from our own `/api/region`; no IP address is stored.

## Not verified

- The mid-session VPN switch has unit tests but was not tried with a real VPN.
- Spanish and Valencian wording has not been reviewed by a native speaker.

## Steps for the owner to publish

1. `git push origin main` (Cloudflare deploys the web app).
2. `npm run build` (postbuild runs `npx cap sync ios`), then archive and upload from Xcode.
3. Build the Android bundle from `android-native` and upload it per `docs/android/release-checklist.md`, then tag `v1.6.1`.
