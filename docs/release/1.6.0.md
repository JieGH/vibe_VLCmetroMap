# Release checklist: Xarxa 1.6.0 (versionCode 4)

Everything since 1.5.0 is `git log 5706924..HEAD` (33 commits on `feat/bus-multimodal-merge`).

## Version places changed

- `android-native/version.properties`: `versionCode=4`, `versionName=1.6.0`. This is the only real source of truth (read by `android-native/app/build.gradle.kts` and `android-native/tools/release-apk.sh`).
- Left alone on purpose: `package.json` (0.0.0), iOS `MARKETING_VERSION = 1.0`, legacy Capacitor `android/version.properties` (1.4.0, separate wrapper app), and the UI `VersionPill` (shows the build date through `__APP_VERSION__` in `vite.config.js`, not a version number).

## Content changed

- What's New: four new 1.6.0 bullets in `WhatsNewModal.jsx`, the en/es/ca dictionaries and `WhatsNewModal.test.jsx`; the 1.5.0 and older bullets are kept (one flat list).
- README: text size up to XXL, wide-desktop behaviour, 320 m / 280 m detection radii, zoom-driven EMT stops.
- Privacy policy: not changed (see below).

## Privacy policy review

No change, effective date stays 26 October 2026. Since 1.5.0: bus arrivals are fetched only for visible stops (fewer requests, same on-demand rule), the train-service refusal notice and diagnostics are local (failure type and status shown only if the user sends feedback), and nothing new is sent anywhere.

## Results

Results from the preparing agent on this branch. Run again before publishing: `npm test -- --run && npm run lint`, then `npm run build`.

- Tests + lint: PASS (90 files, 1256 tests passed; lint 0 errors, vendor warnings only)
- Build: PASS (`npm run build` and iOS sync completed)

## Known unverified items (nothing was checked on a real device)

- Selected stop highlight and centring in the usable map area.
- Two-column line chips on EMT stops at zoom 15 and above.
- Spacing of 10 px between the split view divider and the cards.
- XXL text size layout.
- Desktop 1080p layout (Large text, open and wider sidebar).
- Offset of paired stops is capped at 30 m with TARGET 86 m; a road scan showed this puts many stops far from the road. Needs a decision.
- Midnight rollover bug: `calculateDueSeconds` mishandles a 00:10 arrival around midnight (found in the #90 tests). Not fixed.
- Spanish and Valencian wording: all strings are translated, but the untranslated-wording review list has not been reviewed by a native speaker.

## Steps for the owner to publish

1. Push this branch: `git push origin feat/bus-multimodal-merge`.
2. Merge it into `main` (Netlify deploys the web app from `main`).
3. Run `npm run build` (its postbuild runs `npx cap sync ios`), then archive and upload from Xcode.
4. Build the Android bundle from `android-native` with `versionCode` 4 / `versionName` 1.6.0 and upload it; follow `docs/android/release-checklist.md`, then tag `v1.6.0`.
