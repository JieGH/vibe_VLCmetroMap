# Release notes: Xarxa 1.9.1 (versionCode 11)

A fix release on top of 1.9.0. No new features, so What's New does not pop up again.

## What's new for users

- **The map and the app now always share the same light or dark theme after you reopen the app.** In 1.9.0 the map could stay white under a dark app (or the reverse) if your phone's theme changed while Xarxa was in the background. The map now waits until it has finished loading, then switches to match.
- The app re-checks your phone's theme whenever you come back to it, and a light-mode phone no longer flashes the dark screen on launch.

## Changes for the owner

- `MapView.jsx`: the style swap no longer gives up when `isStyleLoaded()` is false (it is false while tiles load); it waits for `idle` and applies the current theme (`appliedThemeRef`).
- `App.jsx`: re-reads the OS theme on `visibilitychange` and `focus`, and keeps `<meta name="theme-color">` in step.
- `index.html`: sets `data-theme` before first paint.
- Version: `android/version.properties` (`versionCode=11`, `versionName=1.9.1`). What's New key unchanged (`1.9.0`).

## Not verified on a device

- Not tested on a real phone or iPhone; no Android phone was connected, so the APK was built and signed but not installed.
- Known gaps: if the map never goes idle (offline, stalled tiles) it stays on the old theme until the next theme change; Light/Dark picks are not remembered between launches.
